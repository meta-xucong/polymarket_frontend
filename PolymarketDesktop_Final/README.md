# Polymarket Desktop Bundle

## Quick Start

Double-click one of these:

- `PolymarketDesktop.exe` (desktop window)
- `PolymarketWebPanel.exe` (browser mode)

Web URL: `http://127.0.0.1:8787`

## First-Time Config

Edit account keys in:

- `app_root/POLYMARKET_MAKER_copytrade_v2/account.json`
- `app_root/POLY_SMARTMONEY/copytrade_v3_muti/accounts.json`

Only replace your account/private key fields. Keep other defaults unchanged.

## Notes

- This package does not require local Python installation.
- Android app is a Web shell, so a reachable Web panel is required first.
